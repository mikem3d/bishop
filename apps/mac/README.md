# Bishop for Mac (v2)

The desktop companion: an avatar in a screen corner, a speech bubble, an iMessage-style conversation, a large content panel, and the front end for this Mac's Claude Code agent. Built with Tauri 2 + React, sharing `@bishop/core` with the phone app. It bundles `bishop-runner` and the `bishop` CLI (login, link, unlink, status).

`assets/avatar/` holds the avatar in four states (idle, thinking, working, needs you) at 32, 64 and 256px, plus a 64px sprite sheet.
